# ComuniCAP Premium

Aplicación web progresiva de comunicación aumentativa y alternativa creada por **Hadrion** y dirigida profesionalmente por la Lic. Fga. Adriana Soba.

## Producto

- Comunicación mediante símbolos, fotografías y voz.
- Frases frecuentes y personalizadas.
- Anticipador de rutinas y apoyos visuales.
- Actividades terapéuticas e impresión.
- Uso instalable y soporte sin conexión para el contenido local.
- Modos de accesibilidad y personalización profesional.
